This file collects the scholarly works, code repositories, and future publication links associated with the **AiCumene EEG-BCI Sleep–Wake Dataset**.

## Canonical BOID code

**BOID — Brain Oscillator Intrinsic Dimension**

https://github.com/aicumene/BOID

This repository contains the BOID-specific analysis layer (TLS-ESPRIT pole processing, BOID estimation, oscillator descriptors, topology-based analyses, and article-level statistical workflows). The upstream MSSA signal-subspace implementation accompanies a separate methodological preprint and repository.

## Citation practice

Researchers using the public dataset should cite the dataset DOI.

Researchers using BOID, oscillator-dimensionality, Hankel/MSSA, ESPRIT, or related source-estimation methodology should additionally cite the BOID preprint and the method publication(s) relevant to the analysis performed.

When the peer-reviewed journal article *Brain states are organized by regulated oscillator dimensionality* is published, its final citation and DOI should be added to this list and used where scientifically relevant.
