# Public EEG/PSG recordings

This directory is the canonical location within the Zenodo deposit for the 45 publicly released synthetic recordings of the:

**AiCumene EEG-BCI Sleep–Wake Dataset**  
**DOI:** 10.5281/zenodo.22923070

Public record IDs:

`S0001`–`S0045`

Each record consists of:

```text
S00xx-PSG.edf
S00xx-Hypnogram.edf
```

The public signal files are archived on Zenodo and are intentionally not duplicated in the companion GitHub dataset repository.

Companion dataset repository:

https://github.com/aicumene/aicumene-eeg-bci-sleep-wake-dataset

Canonical BOID implementation:

https://github.com/aicumene/BOID
